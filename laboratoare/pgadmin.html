Utilizarea pgAdmin

O dată cu PostgreSQL se instalează pgAdmin 4, o interfață grafică prin care ne conectăm la server, administrăm bazele de date și rulăm comenzi SQL. La laborator vom lucra aproape exclusiv în Query Tool (instrumentul de interogare).

Conectarea la server

În arborele din stânga (Browser) extindeți Servers → PostgreSQL. La prima conectare vi se cere parola utilizatorului postgres (cea setată la instalare). După conectare veți vedea bazele de date sub nodul Databases.

Pentru a lucra, selectați baza de date dorită (de ex. facultate). Toate comenzile rulate în Query Tool se execută pe baza de date curent selectată.

Query Tool

Deschideți Query Tool: click dreapta pe baza de date → Query Tool (sau iconița din bara de sus). Fereastra are un editor (sus) unde scrieți comenzile SQL și o zonă de rezultate (jos).

  • Fiecare comandă SQL se termină cu simbolul punct și virgulă ;.
  • Puteți scrie o comandă pe mai multe rânduri; ea este considerată completă la întâlnirea lui ;.
  • Puteți scrie mai multe comenzi în același editor, fiecare terminată cu ;.

Execuția comenzilor

  • Execute / Refresh (F5) sau butonul ▶ : execută tot textul din editor. Dacă există mai multe comenzi, ele se execută pe rând.
  • Pentru a executa o singură comandă dintr-un script mai mare, selectați (cu mouse-ul) doar textul comenzii dorite și apăsați F5 - se execută doar selecția.
  • Rezultatul unei interogări SELECT apare în tabul Data Output; mesajele și erorile apar în tabul Messages.

Lucrul cu fișiere .sql

  • Open File (iconița folder): încarcă în editor conținutul unui fișier .sql de pe disc. Apoi îl rulați cu F5.
  • Save / Save As (iconița dischetă): salvează conținutul editorului într-un fișier .sql, pentru a-l păstra și a-l reutiliza.

Astfel puteți salva interogările pe care le scrieți (de exemplu pentru a le preda) și puteți rula scripturi pregătite, fără a rescrie comenzile de fiecare dată.

Vizualizarea structurii unei tabele

Dacă ați uitat structura unei tabele (ce coloane are, ce tipuri, dimensiuni), o puteți inspecta în arborele din stânga: baza de date → Schemas → public → Tables, apoi extindeți tabela și nodul Columns.

Alternativ, dacă folosiți consola psql (clientul în linie de comandă al PostgreSQL), comanda echivalentă este:

\d nume_tabel

iar pentru lista tuturor tabelelor:

\dt

Observații

Spre deosebire de comenzile SQL (care sunt trimise serverului PostgreSQL), comenzile care încep cu \ (de exemplu \d, \dt, \i) sunt comenzi specifice utilitarului psql și funcționează doar în consola psql, nu și în Query Tool din pgAdmin. În pgAdmin echivalentele lor se obțin prin interfața grafică (arborele Browser, butoanele Open File etc.).
