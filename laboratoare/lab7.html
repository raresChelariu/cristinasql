Subinterogări necorelate

Subinterogările necorelate sunt fraze SELECT încorporate în clauzele WHERE, HAVING și FROM ale unei interogări (foarte foarte rar se pot intalni in ORDER BY sau in SELECT), adica ale altei fraze SELECT. Subinterogarea necorelată (denumită și interogarea interioară sau interogarea imbricată) se execută o singură dată, înaintea interogării exterioare, cea din urmă utilizând rezultatul subinterogării în general pentru a filtra.

Subinterogarea are în general rolul de extrage valori din baza de date care ulterior vor servi la filtrarea altor înregistrări. Subinterogarea trebuie delimitata de fiecare data de paranteze si poate sa apară doar în partea din dreapta a operatorului de comparatie.

Sintaxa este următoarea:

SELECT ...
    FROM ...
    WHERE expr operator
          (SELECT ...
              FROM ...
              [WHERE ...]
              [GROUP BY...[HAVING...]])
    [GROUP BY...[HAVING...]]
    [ORDER BY...]

Exemple:

SELECT nume, prenume
    FROM studenti
    WHERE nr_matricol IN
          (SELECT nr_matricol
              FROM note
              WHERE valoare=10)
    ORDER BY nume, prenume;
--ce returneaza interogarea de mai sus?

SELECT DISTINCT nume, prenume
    FROM studenti s, note n
    WHERE s.nr_matricol=n.nr_matricol and valoare>
          (SELECT MAX(valoare)
              FROM studenti s, note n
              WHERE s.nr_matricol=n.nr_matricol AND nume='Archip')
    ORDER BY nume, prenume;
--ce returneaza interogarea de mai sus?

Dacă subinterogarea returnează o singură linie rezultat, operatorul poate fi unul standard precum >, =, >=, <, <>, <=. Dacă subinterogarea returnează mai multe linii rezultat se utilizează operatori specifici precum IN, ALL, ANY, SOME.

Într-o interogare pot fi utilizate si mai multe subinterogări:

SELECT DISTINCT nume, prenume
    FROM studenti s, note n
    WHERE s.nr_matricol=n.nr_matricol and valoare>
          (SELECT MAX(valoare)
              FROM studenti s, note n
              WHERE s.nr_matricol=n.nr_matricol AND nume='Archip')
      AND grupa=
          (SELECT grupa FROM studenti WHERE nume='Archip')
    ORDER BY nume, prenume;
--ce returneaza interogarea de mai sus?
--ce s-ar intampla daca am avea doi studenti cu numele Archip, in grupe diferite ?

Subinterogările pot returna mai multe coloane, caz în care condiția e formulată la nivel de tuplu de valori:

SELECT DISTINCT an, grupa, nume, prenume, valoare
    FROM studenti s, note n
    WHERE s.nr_matricol=n.nr_matricol and (grupa,an,valoare) IN
          (SELECT grupa, an, MAX(valoare)
              FROM studenti s, note n
              WHERE s.nr_matricol=n.nr_matricol
              GROUP BY grupa, an)
    ORDER BY an, grupa;
--ce returneaza interogarea de mai sus?

Limitarea numărului de înregistrări: LIMIT și OFFSET

Uneori este necesară limitarea numărului de linii returnate de o interogare. Exemplul clasic general este realizarea unor clasamente de tipul "top n". Pentru baza noastră de date un exemplu specific ar fi "Care sunt primii trei studenți în ordinea descrescătoare a mediilor?"

În PostgreSQL limitarea numărului de linii se face cu clauza LIMIT n (sau, echivalent şi conform standardului SQL, FETCH FIRST n ROWS ONLY), scrisă la finalul interogării. Opţional, clauza OFFSET m sare peste primele m linii.

Spre deosebire de filtrarea din clauza WHERE, clauza LIMIT se aplică după ce întreaga interogare a fost procesată şi ordonată. Ordinea de procesare a clauzelor este următoarea:

  • înregistrările sunt aduse din tabelele specificate în clauza FROM și sunt filtrate conform clauzei WHERE (ce corespunde operatorului de selecție);
  • se creează grupurile conform GROUP BY;
  • se filtrează grupurile conform HAVING;
  • operatorul de proiecție corespunzător listei SELECT este aplicat;
  • se ordonează conform ORDER BY;
  • se limitează numărul de linii conform LIMIT / OFFSET.

Deoarece LIMIT se aplică ultimul, după ORDER BY, putem obţine corect primii trei studenți în ordine alfabetică a numelui și prenumelui astfel:

SELECT * FROM studenti ORDER BY nume, prenume LIMIT 3;

Echivalent, folosind sintaxa standard:

SELECT * FROM studenti ORDER BY nume, prenume FETCH FIRST 3 ROWS ONLY;

Pentru a sări peste primii şi a lua următorii (paginare), folosim OFFSET:

SELECT * FROM studenti ORDER BY nume, prenume LIMIT 3 OFFSET 3;

Observatie: pot manipula pozitia in care apar valorile de null intr-o ordonare prin intermediul cuvintelor cheie "NULLS FIRST" sau "NULLS LAST" scrise dupa clauza ORDER BY.

Subinterogări şi LIMIT în R (tidyverse)

O subinterogare necorelată se execută o singură dată şi produce o valoare (sau o listă de valori) folosită apoi la filtrare. În R o traducem natural: calculăm întâi rezultatul "interior" şi îl stocăm într-o variabilă, apoi îl folosim în filter(). Pentru apartenenţa la o mulţime de valori folosim %in% (echivalentul lui IN), iar pentru subinterogări pe mai multe coloane folosim semi_join().

library(tidyverse)

Subinterogare cu IN

# SELECT nume, prenume FROM studenti
#   WHERE nr_matricol IN (SELECT nr_matricol FROM note WHERE valoare = 10)
matricole_de_10 <- note %>%
  filter(valoare == 10) %>%
  pull(nr_matricol)

studenti %>%
  filter(nr_matricol %in% matricole_de_10) %>%
  arrange(nume, prenume) %>%
  select(nume, prenume)

Subinterogare cu operator scalar (>, =)

# ... WHERE valoare > (SELECT MAX(valoare) ... WHERE nume = 'Archip')
prag <- studenti %>%
  inner_join(note, by = "nr_matricol") %>%
  filter(nume == "Archip") %>%
  summarise(m = max(valoare, na.rm = TRUE)) %>%
  pull(m)

studenti %>%
  inner_join(note, by = "nr_matricol") %>%
  filter(valoare > prag) %>%
  distinct(nume, prenume) %>%
  arrange(nume, prenume)

Subinterogare pe mai multe coloane → semi_join()

# ... WHERE (grupa, an, valoare) IN
#       (SELECT grupa, an, MAX(valoare) ... GROUP BY grupa, an)
maxime <- studenti %>%
  inner_join(note, by = "nr_matricol") %>%
  group_by(grupa, an) %>%
  summarise(valoare = max(valoare, na.rm = TRUE), .groups = "drop")

studenti %>%
  inner_join(note, by = "nr_matricol") %>%
  semi_join(maxime, by = c("grupa", "an", "valoare")) %>%
  distinct(an, grupa, nume, prenume, valoare) %>%
  arrange(an, grupa)

semi_join() păstrează din stânga doar liniile care au corespondent în dreapta - exact ca un IN pe tuplu. (Complementul, anti_join(), corespunde lui NOT IN.)

LIMIT şi OFFSET → slice_head() / slice()

# SELECT * FROM studenti ORDER BY nume, prenume LIMIT 3
studenti %>%
  arrange(nume, prenume) %>%
  slice_head(n = 3)

# LIMIT 3 OFFSET 3  (sări peste primii 3, ia următorii 3)
studenti %>%
  arrange(nume, prenume) %>%
  slice(4:6)

# top n direct după o valoare (ex. primii 3 după bursă)
studenti %>% slice_max(bursa, n = 3)

Exerciții

  1. Afișați numele studenților care iau cea mai mare bursa acordată.
  2. Afișați numele studenților care sunt colegi cu un student pe nume Arhire (coleg = același an si aceeași grupă).
  3. Pentru fiecare grupă afișați numele studenților care au obținut cea mai mică notă la nivelul grupei.
  4. Identificați studenții a căror medie este mai mare decât media tuturor notelor din baza de date. Afișați numele și media acestora.
  5. Afișați numele și media primilor trei studenți ordonați descrescător după medie.
  6. Afișați numele studentului (studenților) cu cea mai mare medie precum și valoarea mediei (atenție: limitarea numărului de linii poate elimina studenții de pe poziții egale; găsiți altă soluție).
  7. Afişaţi numele şi prenumele tuturor studenţilor care au luat aceeaşi nota ca şi Ciprian Ciobotariu la materia Logică. Excludeţi-l pe acesta din listă. (Se știe în mod cert că există un singur Ciprian Ciobotariu și că acesta are o singură notă la logică)
  8. Din tabela studenti, afisati al cincilea prenume in ordine alfabetica.
  9. Punctajul unui student se calculeaza ca fiind o suma intre produsul dintre notele luate si creditele la materiile la care au fost luate notele. Afisati toate informatiile studentului care este pe locul 3 in acest top.
  10. Afișați studenții care au notă maximă la o materie precum și nota și materia respectivă.
