Funcții linie

Funcţiile de tip linie sunt funcţii care, utilizate în interogări, sunt apelate pentru fiecare linie și returnează un rezultat pe linie pentru tabelul interogat. Argumentul funcțiilor poate fi o simplă constantă dată de utilizator, numele unei variabile, numele unei coloane sau o expresie.

Pot fi utilizate în cadrul listei SELECT, în clauzele WHERE, ORDER BY.

Apelate cu argument NULL funcţiile returnează în general NULL. Excepţie fac CONCAT, COALESCE, REPLACE şi REGEXP_REPLACE.

Funcţiile listate în continuare sunt cele oferite de PostgreSQL.

Funcţii numerice

primesc ca argument şi returnează date de tip numeric

FunctiaDescriereExemplu
CEIL (n) Rotunjeşte superior pe n SELECT CEIL(51.3);
FLOOR(n) Rotunjeşte inferior pe n SELECT FLOOR(51.3);
ROUND(n [,m]) Rotunjeşte pe n la m zecimale. Implicit m este 0, echivalent cu rotunjirea la cel mai apropiat întreg. m poate fi şi negativ. SELECT ROUND(21.365,2) AS "Rotunjire - pozitiv", ROUND (21.665,-1) AS " Rotunjire - negativ ";
TRUNC(n [,m]) Trunchează pe n la m zecimale; implicit m e 0; m poate fi şi negativ. SELECT TRUNC(21.365,2) AS "Trunchiere - pozitiv", TRUNC(21.665,-1) AS " Trunchiere - negativ";
MOD(m, n) Returnează restul împărţirii lui m la n SELECT MOD (26,11) AS "Mod";

La acestea se mai adaugă funcţiile trigonometrice uzuale (COS(n), ACOS(n), SIN(n), ASIN(n), TAN(n), ATAN(n)), funcţiile de calcul de logaritmi (LN(n), LOG(base, n)), ridicarea la putere (EXP(n), POWER(m,n), rădăcina pătrată (SQRT(n)).

ASCII (char) Returnează codul ASCII al primului character din şir SELECT ASCII('A');

Funcţii ce iau ca argument date caracter și returnează date de tip caracter

FunctiaDescriereExemplu
INITCAP(char) Prima literă a fiecărui cuvânt e transformată în majusculă. SELECT INITCAP('prima litera majuscula');
UPPER(char) Returnează şirul char rescris cu majuscule SELECT UPPER('Stefan');
LOWER(char) Returnează şirul char rescris cu litere mici SELECT LOWER('LOWER');
REVERSE(char) Returnează şirul char rescris de la coadă la cap SELECT REVERSE('OREZ');
CONCAT(char1, char2) Concatenează şirurile argument echivalent cu operatorul de concatenare SELECT CONCAT( CONCAT(nume, ' este student in anul '), an) FROM studenti;
SUBSTR(char, m [, n ]) Extrage din şirul char n caractere începând de la poziţia m; omisiunea lui n semnifică finalul şirului; o valoare negativă pentru m semnifică numărarea de la stânga la dreapta SELECT SUBSTR('ABCDEFG',3,4);
RPAD(char1,n [,char2 ]) Returnează char1 cu spaţii adăugate la dreapta până la lungimea n, dacă se omite char2; altfel char2 este copiat de oricâte ori e nevoie pentru a completa char1 până la lungimea n SELECT RPAD(nume,12,'ab') FROM studenti WHERE nume = 'Popescu';
LPAD(char1,n [,char2 ]) Similar RPAD cu diferenţa că alipirea se face la stânga SELECT LPAD('Pagina',15,'*.');
CHR(n) Returnează caracterul corespunzător codului n, ca tip text SELECT CHR(68)||CHR(65)||CHR(84)||CHR(69);
TRIM (char) Elimină spaţiile goale de la inceputul şi sfârşitul textului SELECT '-'||TRIM('   test   ')||'-' AS "Fara spatii";
LTRIM(char) Elimină spaţiile goale de la inceputul textului SELECT '-'||LTRIM('   test   ')||'-' AS "Fara spatiile de la inceput";
REPLACE(char, search_string [, replacement_string]) Returnează şirul char în care subşirul search_string este înlocuit de replacement_string; absenţa ultimului reprezintă ştergerea tuturor apariţiilor subşirului căutat SELECT REPLACE('Andrei','i','ea');
TRANSLATE(char, from, to) Returnează char modificat astfel: fiecare apariţie a unui character din şirul from este înlocuită de corespondentul (caracterul de pe aceeaşi poziţie) din şirul to; dacă from este mai lung decât to, caracterele fără corespondent sunt şterse SELECT TRANSLATE('48KLM980', '0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ', '9999999999XXXXXXXXXXXXXXXXXXXXXXXXXX') "COD";

Funcțiile care schimbă case-ul literelor (transformă textul în litere mici sau în majuscule) sunt frecvent utilizate în clauza WHERE pentru a regăsi text. De exemplu, dacă dorim identificarea datelor despre studentul Andrei și nu avem garanția că prenumele acestuia a fost inserat în baza de date cu toate litere majuscule sau doar cu prima literă majusculă, vom procesa atributul prenume aducându-l la forma dorită pentru testare:

SELECT * FROM studenti WHERE prenume = 'ANDREI'; --returneaza 0 linii
SELECT * FROM studenti WHERE UPPER(prenume) = 'ANDREI'; --returneaza înregistrările dorite

De asemenea funcția TRIM are o largă utilizare pentru regăsirea datelor atunci cand atributele sunt declarate de tip CHAR:

SELECT * FROM profesori WHERE UPPER(nume) = 'BREABAN'; --returneaza 0 linii
SELECT * FROM profesori WHERE TRIM(UPPER(nume)) = 'BREABAN'; --returneaza înregistrările dorite
 SELECT TRIM('1' FROM '1test1'); -- elimina caracterul de la inceput si de la sfarsit din "1test1"
 SELECT TRIM(LEADING '0' FROM '00010230'); -- Elimina zerourile de la inceput
 SELECT TRIM(TRAILING '1' FROM 'Tech1'); -- elimina caracterele '1' de la sfarsit
 SELECT TRIM(BOTH '1' FROM '123Tech111'); -- elimina caracterele '1' de la inceput si de la sfarsit

Funcţii pentru tipul DATE (date calendaristice)

Formatul implicit pentru afişarea datelor calendaristice în PostgreSQL este ISO, "YYYY-MM-DD" (ex: '2015-06-10'). Constantele de tip dată se pot scrie ca literali tipaţi, de ex. DATE '2015-06-10', sau folosind funcţia TO_DATE (descrisă mai jos) care specifică explicit formatul şirului introdus, evitând ambiguităţile.

CURRENT_TIMESTAMP Returnează data, ora si fusul orar curente relative la zona de timp (time zone) a sesiunii curente SELECT CURRENT_TIMESTAMP;
NOW()

SELECT TO_CHAR(NOW(), 'DD-MM-YYYY HH24:MI');

   + EXTRACT(MONTH FROM AGE(DATE '2015-02-02', DATE '2015-01-01')) AS "Luni";

DATE_TRUNC(unitate, d) Trunchiază data la unitatea specificată ('year', 'month', 'day', 'hour'...). Înlocuieşte rotunjirea/trunchierea datelor. SELECT DATE_TRUNC('year', DATE '2016-10-27') AS "Prima zi a anului";
SELECT DATE_TRUNC('month', DATE '2016-10-27') AS "Prima zi a lunii";

Studiaţi modelele de format pentru date la adresa documentaţia PostgreSQL (măcar astea să ştiţi ce fac: D, DAY, DD, HH24, MI, MM, MON, MONTH, SS, YYYY, YY, YEAR).

În PostgreSQL datelor calendaristice li se pot aplica operaţii aritmetice cu numere întregi (zile) şi cu intervale:

  • adunarea sau scăderea unui număr (de zile) la/dintr-o dată are ca rezultat o nouă dată:
SELECT CURRENT_DATE + 10;

Valoarea adunată reprezintă un număr de zile. Pentru a adăuga ore folosim un interval, de ex. NOW() + INTERVAL '5 hours'.

  • diferența a două date are ca rezultat numărul de zile
 SELECT (CURRENT_DATE - data_nastere)/365 FROM studenti;

Funcţii de conversie

În PostgreSQL conversiile între tipuri se fac explicit, fie cu funcţiile de mai jos, fie cu operatorul de cast ::tip (de ex. '123'::integer sau bursa::text). Spre deosebire de alte sisteme, PostgreSQL nu converteşte automat un text într-un număr într-o expresie aritmetică.

Pentru conversii există funcţiile:

FunctiaDescriereExemplu
TO_CHAR(n [, fmt]) Converteşte o valoare numerică n la text conform formatului specificat fmt. Studiați formatul numeric în documentaţia PostgreSQL. SELECT TO_CHAR(1110 + 1, '9999');
SELECT TO_CHAR(bursa,'99999') FROM studenti;
TO_CHAR(datetime [, fmt ]) Converteşte o dată/timp la text conform formatului specificat fmt SELECT TO_CHAR(CURRENT_DATE, 'Day, Month, DD, YYYY') AS "Exemplu TO_CHAR";
TO_DATE(char, fmt) Convertește un șir de caractere în dată calendaristică conform formatului specificat. Modelele de format sunt descrise în documentaţia PostgreSQL. SELECT TO_DATE('January 26, 1996', 'Month DD YYYY');
TO_NUMBER(char, fmt) Converteşte un şir de caractere într-un număr conform formatului specificat. SELECT TO_NUMBER('100.52','9999.99');
CAST(expr AS type_name)
expr::type_name		 Conversie explicită de tip. SELECT CAST(CURRENT_TIMESTAMP AS VARCHAR(50));
SELECT CURRENT_TIMESTAMP::VARCHAR(50);

Exemple in care data calendaristica (ziua/luna) este afişată în limba română. Numele localizate se obţin cu modificatorul TM (Translated Month/Day), care foloseşte localizarea sesiunii. Setaţi întâi localizarea pentru timp:

SET lc_time = 'ro_RO';
SELECT 'Este o zi frumoasa de ' || TO_CHAR(CURRENT_DATE, 'TMMonth');
SELECT nume, prenume, TO_CHAR(data_nastere, 'TMDay') AS "zi nastere" FROM studenti;

Alte funcţii

FunctiaDescriereExemplu
CURRENT_USER Returnează numele utilizatorului curent SELECT CURRENT_USER;
COALESCE(expr1, expr2 [, ...]) Returnează prima expresie care nu este NULL din listă SELECT nume, COALESCE(bursa,0) AS "bursa" FROM studenti;

CASE WHEN conditie THEN rezultat
[WHEN ...] [ELSE default] END 		Expresie condiţională: evaluează condiţiile pe rând şi returnează rezultatul primei condiţii adevărate; dacă niciuna nu e adevărată returnează ELSE (sau NULL). SELECT CASE bursa WHEN 450 THEN 'premiul 1' WHEN 350 THEN 'premiul 2' WHEN 250 THEN 'premiul 3' ELSE '?' END FROM studenti;

Funcția COALESCE este deseori utilă pentru a evita rezultatele nule la aplicarea unor operatori/funcții. De exemplu, dacă toți studenții facultății ar fi finanțați cu o sumă dată (de ex. 100), suma totală ridicată de un student nu se poate obține prin

SELECT 100+bursa FROM studenti;

ci prin

SELECT 100+COALESCE(bursa,0) FROM studenti;

Aceleaşi funcţii linie în R (tidyverse)

Funcţiile linie din SQL se aplică element cu element pe o coloană; în R, funcţiile sunt deja "vectorizate" (se aplică automat fiecărui element al vectorului/coloanei), aşa că le folosim direct în mutate() sau filter(). Pentru şiruri folosim pachetul stringr, iar pentru date calendaristice pachetul lubridate (ambele incluse în tidyverse).

library(tidyverse)
library(lubridate)

Funcţii numerice

# CEIL(51.3) / FLOOR(51.3)
ceiling(51.3)            # 52
floor(51.3)             # 51
# ROUND(21.365, 2)
round(21.365, 2)
# TRUNC(21.365, 2)
trunc(21.365 * 100) / 100
# MOD(26, 11)
26 %% 11
# pe o coloană:
note %>% mutate(rotunjit = round(valoare, 1))

Şiruri → numeric

# LENGTH('cuvant')
str_length("cuvant")        # sau nchar("cuvant")
# ASCII('A')
utf8ToInt("A")[1]          # 65
# POSITION('OR' IN 'CORPORATE') / STRPOS(...)
str_locate("CORPORATE", "OR")[, "start"]
profesori %>% mutate(poz = str_locate(nume, "ra")[, "start"])

Şiruri → şiruri

# INITCAP -> str_to_title ; UPPER/LOWER -> str_to_upper/str_to_lower
str_to_title("prima litera majuscula")
str_to_upper("Stefan")
str_to_lower("LOWER")
# REVERSE('OREZ')
stringi::stri_reverse("OREZ")
# CONCAT(nume, ' este student in anul ', an)
studenti %>% mutate(txt = str_c(nume, " este student in anul ", an))
# SUBSTR('ABCDEFG', 3, 4)
str_sub("ABCDEFG", 3, 3 + 4 - 1)        # "CDEF"
# RPAD / LPAD
str_pad("Pagina", 15, side = "right", pad = "*")
str_pad("Pagina", 15, side = "left",  pad = "*")
# TRIM / LTRIM / RTRIM
str_trim("  test  ")            # ambele capete
str_trim("  test  ", side = "left")
# REPLACE('Andrei', 'i', 'ea')
str_replace_all("Andrei", "i", "ea")
# TRANSLATE(char, from, to)
chartr("0123456789", "9999999999", "48KLM980")

La fel ca în SQL, aducerea textului la aceeaşi formă (case / trim) este utilă în filtrare:

# WHERE UPPER(prenume) = 'ANDREI'
studenti %>% filter(str_to_upper(prenume) == "ANDREI")
# WHERE TRIM(UPPER(nume)) = 'BREABAN'   (utile pentru coloane CHAR)
profesori %>% filter(str_to_upper(str_trim(nume)) == "BREABAN")

Funcţii pentru date calendaristice

# CURRENT_DATE / NOW()
Sys.Date()
Sys.time()                  # sau lubridate::now()
# AGE(d1, d2) -> diferenţa ca interval; nr. de luni:
interval(ymd("2015-01-01"), ymd("2015-02-02")) %/% months(1)
# data_nastere + INTERVAL '1 month'
studenti %>% mutate(luna_viitoare = data_nastere %m+% months(1))
# CURRENT_DATE + 10  (adună 10 zile)
Sys.Date() + 10
# diferenţa a două date (în zile) / vârsta în ani
studenti %>% mutate(varsta = as.numeric(Sys.Date() - data_nastere) %/% 365)
# EXTRACT(DOW FROM d) -> ziua săptămânii ; DATE_TRUNC('month', d)
wday(ymd("2015-10-13"))          # ziua săptămânii
floor_date(ymd("2016-10-27"), "month")   # prima zi a lunii
# ultima zi din lună
ceiling_date(Sys.Date(), "month") - days(1)

Funcţii de conversie

# TO_CHAR(data, 'DD-MM-YYYY')   -> format()
format(Sys.Date(), "%d-%m-%Y")
# TO_CHAR(data_nastere, 'TMDay') -> ziua în română (cu locale setat)
studenti %>% mutate(zi = format(data_nastere, "%A"))
# TO_DATE('January 26, 1996', 'Month DD YYYY')
as.Date("January 26, 1996", format = "%B %d %Y")

Alte funcţii (COALESCE, NULLIF, CASE, LEAST/GREATEST)

# COALESCE(bursa, 0) -> prima valoare ne-NA
studenti %>% mutate(bursa = coalesce(bursa, 0))
# NULLIF(expr1, expr2)
na_if(x, 0)                  # returnează NA dacă x == 0
# 100 + COALESCE(bursa, 0)
studenti %>% mutate(total = 100 + coalesce(bursa, 0))
# CASE WHEN bursa = 450 THEN 'premiul 1' ... ELSE 'mentiune' END
studenti %>%
  mutate(premiu = case_when(
    bursa == 450 ~ "premiul 1",
    bursa == 350 ~ "premiul 2",
    bursa == 250 ~ "premiul 3",
    TRUE         ~ "mentiune"
  ))
# LEAST / GREATEST  -> pmin / pmax (element cu element)
pmin("Mihai", "Andrei", "Anca")
pmax("Stefan", "Mihai", "Andrei", "Anca")
