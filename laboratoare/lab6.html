Funcţii de agregare în SQL

Funcţiile de agregare sunt funcţii care, utilizate în interogări, returnează o singură linie rezultat pe baza unui grup de linii. Pot fi utilizate în cadrul listei de câmpuri ce trebuie returnate de comanda SELECT, în clauzele ORDER BY şi HAVING.

ATENȚIE: nu utilizați funcțiile de agregare în clauza WHERE !!!

Funcţiile de agregare pot accepta clauzele

  • DISTINCT – specifică luarea în considerare doar a valorilor distincte de către funcţie
  • ALL – este implicit, determină funcţia de agregare sa calculeze rezultatul pe baza tuturor valorilor
Operator Descriere Exemplu
COUNT ({ *|[DISTINCT|ALL] expr}) Returnează numărul de linii. Dacă argumentul este * se numără şi valorile NULL, altfel se numără doar valorile nenule. Argumentul poate lua tipul CHAR, VARCHAR, NUMERIC, DATE. SELECT COUNT(*) AS "Total studenti" FROM studenti;
SELECT COUNT(COALESCE(bursa,0)) AS "Total studenti" FROM studenti;
SELECT COUNT(bursa) AS "Studenti bursieri" FROM studenti;
SELECT COUNT(DISTINCT bursa) AS "Variante bursa" FROM studenti;
AVG ([DISTINCT|ALL]n) Returnează media valorilor. Argumentul trebuie să fie numeric. SELECT AVG(valoare) FROM note;
MAX ([DISTINCT|ALL]expr) Returnează valoare maximă. Argumentul poate lua tipul CHAR, VARCHAR, NUMERIC, DATE SELECT MAX(bursa) FROM studenti;
MIN ([DISTINCT|ALL]expr) Returnează valoare minimă. Argumentul poate lua tipul CHAR, VARCHAR, NUMERIC, DATE SELECT MIN(bursa) FROM studenti;
STDDEV ([DISTINCT|ALL]x) Returnează deviatia standard a valorilor. Argumentul trebuie să fie numeric. SELECT STDDEV(bursa) AS "Deviatie standard" FROM studenti;
VARIANCE ([DISTINCT|ALL]x) Returnează varianţa valorilor. Argumentul trebuie să fie numeric. SELECT VARIANCE(bursa) AS "Varianta" FROM studenti;
SUM([DISTINCT|ALL]n) Returnează suma valorilor. Argumentul trebuie să fie numeric. SELECT SUM(bursa) FROM studenti;

Toate funcţiile de agregare ignoră valorile NULL. Excepţie face funcţia COUNT cu argumentul * care numără toate liniile, inclusiv cele cu valori NULL. Pentru ca valoarea NULL să fie luată în considerare se poate utiliza COALESCE în cadrul funcţiei de agregare pentru a substitui NULL cu o valoare anume (ex. 0).

Dacă setul de date nu conţine linii sau conţine doar linii cu valori NULL ca argumente a funcţiilor de agregare, funcţia va returna NULL. Excepţie face COUNT care returnează 0 sau un alt număr.

Gruparea datelor

Toate exemplele ilustrate anterior aplică funcțiile de agregare asupra intregului conținut al tabelului, rezultatul interogării fiind alcătuit dintr-o singură linie.

Funcțiile de agregare sunt însa utilizate în general împreună cu clauza GROUP BY care specifică împărţirea liniilor tabelului interogat în mai multe grupuri; PostgreSQL aplică funcţiile de agregare fiecărui astfel de grup returnând un singur rezultat pentru fiecare grup.

Reamintim sintaxa interogării:

SELECT [DISTINCT | ALL] {* | [expresie_coloana [AS nume_nou]] [,...] }
   FROM nume_tabel [alias] [, ...]
   [WHERE conditie]
   [GROUP BY expresie [HAVING conditie] ]
   [ORDER BY expresie1 [ASC|DESC][,…]]

Exemplu:

SELECT MAX(valoare) FROM note GROUP BY nr_matricol; --Câte linii sunt returnate? Ce reprezintă fiecare linie?

Valori individuale nu pot fi utilizate în lista select decât dacă în clauză GROUP BY este specificată coloana individuală. Deci toate câmpurile din lista select care nu sunt utilizate în cadrul funcţiilor de agregare trebuie să apară în clauza GROUP BY.

Exemplu:

SELECT MAX(valoare), id_curs FROM note GROUP BY nr_matricol; --De ce nu merge?

Grupurile pot fi create și pe baza mai multor atribute:

Exemplu:

SELECT an, count(*) FROM cursuri GROUP BY an; --Cate grupuri?
SELECT credite, count(*) FROM cursuri GROUP BY credite; --Cate grupuri?
SELECT an, credite, count(*) FROM cursuri GROUP BY an, credite ORDER BY an, credite;--Cate grupuri?

Nu este obligatoriu ca atributele utilizate in clauza GROUP BY să apară în lista select; este însă indicată includerea acestora pentru ca înregistrările rezultat să poată fi interpretate.

Filtrarea grupurilor

Clauza WHERE elimină valori individuale (linii) înainte de a avea loc gruparea.

Clauza HAVING este utilizată doar în conjuncţie cu clauza GROUP BY având rolul de a elimina unele grupuri pe baza rezultatului funcţiilor de agregare şi nu a valorilor individuale ale liniilor.

Exemplu:

SELECT id_curs, COUNT(valoare) FROM note GROUP BY id_curs;--Cate grupuri?
SELECT id_curs, COUNT(valoare) FROM note WHERE valoare>8 GROUP BY id_curs;--Cate grupuri? De ce?
SELECT id_curs, COUNT(valoare) FROM note GROUP BY id_curs HAVING COUNT(valoare)>8; --Cate grupuri? De ce?

Agregare şi grupare în R (tidyverse)

Funcţiile de agregare din SQL se calculează în R cu summarise(), care reduce mai multe linii la una singură. Gruparea (GROUP BY) se face cu group_by() înainte de summarise(), iar filtrarea grupurilor (HAVING) cu un filter() aplicat după agregare. Atenţie: la fel ca în SQL, funcţiile de agregare ignoră valorile lipsă - în R asta se obţine cu na.rm = TRUE.

library(tidyverse)

Funcţiile de agregare SQL ↔ R

SQLR (în summarise)
COUNT(*)n()
COUNT(bursa)sum(!is.na(bursa))
COUNT(DISTINCT bursa)n_distinct(bursa)
AVG(valoare)mean(valoare, na.rm = TRUE)
MAX / MINmax(...) / min(...)
SUM(bursa)sum(bursa, na.rm = TRUE)
STDDEV / VARIANCEsd(...) / var(...)

Agregare pe tot tabelul (fără grupare)

# SELECT COUNT(*) AS total_studenti FROM studenti
studenti %>% summarise(total_studenti = n())

# SELECT AVG(valoare) FROM note
note %>% summarise(media = mean(valoare, na.rm = TRUE))

# SELECT MAX(bursa), MIN(bursa), SUM(bursa) FROM studenti
studenti %>% summarise(
  maxim = max(bursa, na.rm = TRUE),
  minim = min(bursa, na.rm = TRUE),
  total = sum(bursa, na.rm = TRUE)
)

Gruparea datelor (GROUP BY)

# SELECT MAX(valoare) FROM note GROUP BY nr_matricol
note %>%
  group_by(nr_matricol) %>%
  summarise(nota_max = max(valoare, na.rm = TRUE))

# SELECT an, COUNT(*) FROM cursuri GROUP BY an
cursuri %>%
  group_by(an) %>%
  summarise(nr = n())

# grupare pe mai multe atribute + ordonare
# SELECT an, credite, COUNT(*) FROM cursuri GROUP BY an, credite ORDER BY an, credite
cursuri %>%
  group_by(an, credite) %>%
  summarise(nr = n(), .groups = "drop") %>%
  arrange(an, credite)

Filtrarea grupurilor (WHERE vs HAVING)

# WHERE: filtrează liniile ÎNAINTE de grupare
# SELECT id_curs, COUNT(valoare) FROM note WHERE valoare > 8 GROUP BY id_curs
note %>%
  filter(valoare > 8) %>%
  group_by(id_curs) %>%
  summarise(nr = sum(!is.na(valoare)))

# HAVING: filtrează grupurile DUPĂ agregare
# SELECT id_curs, COUNT(valoare) FROM note GROUP BY id_curs HAVING COUNT(valoare) > 8
note %>%
  group_by(id_curs) %>%
  summarise(nr = sum(!is.na(valoare))) %>%
  filter(nr > 8)

Regula de aur se vede clar în R: filter() înainte de group_by() = WHERE, iar filter() după summarise() = HAVING.
