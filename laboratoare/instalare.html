Instalarea PostgreSQL și pgAdmin

Pentru laboratoarele de Baze de date vom folosi sistemul de gestiune a bazelor de date PostgreSQL, unul dintre cele mai populare SGBD-uri relaționale, împreună cu interfața grafică pgAdmin. Tot lucrul la laborator (scrierea și rularea scripturilor SQL) se va face din pgAdmin.

Descărcați installer-ul de pe pagina oficială: https://www.postgresql.org/download/ (pe Windows este recomandat installer-ul EDB, care include și serverul PostgreSQL, și pgAdmin 4). Versiunea PostgreSQL 14 sau mai nouă este suficientă pentru buna desfășurare a orelor de laborator.

Pașii de instalare

  • Rulați installer-ul și parcurgeți pașii (Next). Bifați componentele PostgreSQL Server și pgAdmin 4.
  • În timpul instalării vi se va cere o parolă pentru utilizatorul administrator postgres. Rețineți această parolă - veți avea nevoie de ea la prima conectare din pgAdmin.
  • Lăsați portul implicit 5432.
  • La final, serverul PostgreSQL pornește automat ca serviciu, iar pgAdmin 4 poate fi deschis din meniul Start.

Crearea unei baze de date

Deschideți pgAdmin 4. La prima pornire vi se va cere o parolă master (parola pentru pgAdmin) și apoi parola utilizatorului postgres setată la instalare, pentru a vă conecta la server (în arborele din stânga: Servers → PostgreSQL).

O dată conectați, creați o bază de date proprie pentru laborator:

  • click dreapta pe Databases → Create → Database...;
  • la Database scrieți numele facultate și apăsați Save.

Alternativ, puteți crea baza de date scriind o comandă SQL (vezi mai jos cum se deschide Query Tool):

CREATE DATABASE facultate;

Query Tool - rularea comenzilor

Selectați baza de date facultate în arborele din stânga, apoi deschideți instrumentul de interogare: click dreapta pe baza de date → Query Tool (sau iconița Query Tool din bara de sus).

În fereastra Query Tool scrieți o comandă de test și executați-o cu tasta F5 (sau butonul ▶ Execute):

SELECT 1;

Dacă în partea de jos apare rezultatul (valoarea 1), totul funcționează și puteți începe lucrul la Laborator 1. Pentru detalii despre folosirea Query Tool consultați secțiunea Ghid pgAdmin.

Rularea unui script SQL

Multe laboratoare vă cer să rulați un script (un fișier .sql ce conține mai multe comenzi). Pentru a rula un astfel de fișier din pgAdmin:

  • asigurați-vă că sunteți conectați la baza de date corectă (facultate) și aveți Query Tool deschis;
  • apăsați iconița Open File (folder) din Query Tool și selectați fișierul .sql dorit;
  • conținutul fișierului se încarcă în editor; apăsați F5 pentru a executa toate comenzile din script.

Astfel, în loc să scrieți manual zeci de comenzi, puteți rula scripturi pregătite (de exemplu scriptul care creează și populează tabelele folosite la laborator).
